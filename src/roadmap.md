# Roadmap

## Upcoming Initiatives

- Increase JIT performance as new optimization opportunities appear.
- [ ] Add I/O capabilities, including file loading and parsing.
- [ ] Introduce a lightweight built-in task scheduler/helper.
- [ ] Implement multithreading support via multi-VM spawning with result collection on the main VM thread, plus shared atomic metadata to coordinate safely across threads.
- [ ] Expand lust-analyzer LSP features such as identifier and module completions for `use` statements.
- [ ] Provide additional language configuration to toggle built-in modules and features for sandboxed environments (for example, disabling I/O for game scripting).
